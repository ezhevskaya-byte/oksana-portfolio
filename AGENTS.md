# Правила работы с проектом

- Сохранять утверждённый дизайн, тексты и поведение сайта.
- Не переделывать Smart Brief, логику Марка и Cloudflare Worker без конкретной задачи.
- Вносить только минимально необходимые изменения; избегать несвязанного рефакторинга.
- Перед работой изучать Git-статус и существующие изменения. Не уничтожать чужую работу и не восстанавливать файлы массово.
- Соблюдать `.gitattributes`; не проводить массовое преобразование окончаний строк без отдельной задачи.
- Не раскрывать секреты, API-ключи, токены и персональные данные в коде, документации, логах и отчётах. Для примеров использовать заглушки; локальные секреты не добавлять в Git.
- Проверять результат: изучать diff, запускать соответствующие локальные проверки, проверять затронутые страницы.
- Для Worker использовать `npm run check` и `npm test` из `smart-brief-worker`. Live-проверки и обращения к внешним провайдерам требуют отдельной задачи.
- Не публиковать изменения самостоятельно: commit, push, deploy и изменение DNS, хостинга или production-секретов допускаются только по явному разрешению пользователя.
- После работы сообщать состав изменений, результаты проверок и оставшиеся ограничения.
